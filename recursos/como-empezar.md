# Cómo utilizar las prácticas

GitHub muestra los archivos Markdown directamente. Puedes copiar los prompts desde cada archivo.

Para descargar todo el repositorio, selecciona **Code → Download ZIP**. Los archivos binarios de cada episodio (Excel, XML o HTML) se incorporan después de su revisión; comprueba en el README de la práctica cuáles están disponibles.

1. Lee el README del episodio.
2. Copia el prompt correspondiente y adjunta los datos indicados.
3. Para una auditoría independiente, utiliza otra conversación y no reveles previamente los resultados de referencia.
4. Consulta VALIDACION.md para entender el alcance de las pruebas.

**Privacidad:** no subas información real de contribuyentes o clientes sin evaluar permisos, confidencialidad y políticas de tratamiento de datos.
